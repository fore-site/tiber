Tiber is a notification delivery platform that decides _when_ to send each message — and never _what it says_. Trained ML models choose send times and order batched digests; client content is delivered verbatim, behind production-grade reliability infrastructure (queues, retries, dead-letter handling, idempotency, provider failover). That authorship boundary is deliberate: decision AI and generative AI have different failure modes, and a notification platform clients trust is one that never rewrites their words. It includes a self-built data simulator that generates realistic synthetic user engagement data, and that simulator is itself an engineered, documented component, not a throwaway script.

The system demonstrates: async distributed processing, provider/channel abstraction designed for extensibility, ML model training/evaluation with honest metrics, a deliberate authorship boundary (ML decides timing and ordering; clients own every word), observability, and a deployed, demoable product.
